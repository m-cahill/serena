### D. Root cause hypothesis

- **`vars(shared.cmd_opts)`** includes keys whose value is **`None`** for optional CLI strings (e.g. **`loglevel`**, **`models_dir`**, **`ckpt_dir`**, **`vae_dir`**, **`gfpgan_model`**, …).
- **`FlagsModel`** builds fields as **`str`** when **`argparse` default is `None`** (`modules/api/models.py` loop uses `_type = str` unless default is non-`None`).
- **Pydantic v2 `model_validate`** treats explicit **`None`** as input and rejects it for **`str`** fields.
- **Smoke** uses **Pydantic v1** + **`parse_obj`**, which tolerates this combination more leniently in practice.
- **Quality** uses **Pydantic v2** → stricter validation → **500** on `/sdapi/v1/cmd-flags`.
